# 键位

qi 的键位是**固定的**:没有 `keybindings.json` 这类配置文件。要加自己的键,写一个扩展用
`api.register_shortcut("ctrl+x", handler)`(key 用 Textual 的写法;坏键名只提示,不让启动失败)。

TUI 里 `/hotkeys` 会列出当前生效的键位,并如实标出哪些还没做。

## 主键位

| 键 | 行为 |
| --- | --- |
| `escape` | 中断当前回合:**协作式**(未执行的工具补上"已中断"结果、半截回答照常落盘);再按一次、或 3s 宽限期到点仍未收尾 → 强制终止 |
| `escape` ×2 | 空编辑器连按两次(500ms 内):按 `settings.doubleEscapeAction` 开 `/tree` 或 `/fork`(默认 `tree`) |
| `ctrl+c` | 清空输入框;再按一次退出 |
| `ctrl+d` | 输入框为空时退出;非空删右侧字符 |
| `ctrl+o` | 展开 / 折叠工具输出(压缩块也用它展开看摘要) |
| `ctrl+t` | 显示 / 隐藏思考块 |
| `shift+tab` | 循环思考级别(off → minimal → … → max → off) |
| `ctrl+x` | 复制最后一条回答 |
| `ctrl+g` | 用 `$EDITOR` 编辑当前输入 |
| `ctrl+l` | 模型选择器(与 `/model` 同一个) |
| `ctrl+p` / `ctrl+shift+p` | 下一个 / 上一个模型(轮换清单由 `/scoped-models` 决定) |
| `ctrl+z` | 挂起(回到 shell) |

## 输入层(多行编辑器)

| 键 | 行为 |
| --- | --- |
| `enter` | 提交 |
| `shift+enter` / `ctrl+j` | 换行 |
| `ctrl+b` / `ctrl+f` | 光标左 / 右 |
| `↑` / `↓` | 没有补全面板时翻输入历史(首次进入留住草稿、手动改动即退出);否则移动光标 |
| `alt+b` `alt+f` `alt+←/→` | 按词移动 |
| `alt+d` | 删后一个词 |
| `ctrl+-` | 撤销(`ctrl+z` 留给挂起) |
| `ctrl+w` / `ctrl+u` / `ctrl+k` / `alt+backspace` | 删词 / 删到行首 / 删到行尾 |
| `ctrl+y` / `alt+y` | kill-ring 的 yank / yank-pop(删掉的文本进环、连续删合并) |
| `ctrl+v` | 粘贴(含括号粘贴,多行可用) |

编辑器最多 8 行(矮终端还会再降);长高的部分由 transcript 让位。

## 补全面板

| 键 | 行为 |
| --- | --- |
| 行首 `/xx` | 命令名补全 |
| `/model` `/thinking` `/login` | 参数补全(模型 `provider/model` / 思考级别 / provider) |
| `@xx`(任意位置) | 路径补全:装了 `fd` 走全树搜索(尊重 `.gitignore`),否则只扫当前目录一层;目录优先 |
| `tab` | 接受候选(**无候选时仍是缩进**) |
| `↑` / `↓` | 面板开着时选候选;否则翻输入历史 / 移动光标 |
| `escape` | 先关面板,再考虑中断 |

## 会话选择器(`/resume`)

| 键 | 行为 |
| --- | --- |
| 输入框打字 | 过滤:空格分词(模糊子序列)/ `"短语"` 精确连续 / `re:<正则>` 正则 |
| `tab` | 切换范围:**当前目录**(默认)↔ 全部 |
| `↑` / `↓` / `enter` | 选 / 恢复 |
| `ctrl+n` | 只看命名会话 |
| `ctrl+s` | 排序循环:树状 → 最近 → 最相关 |
| `ctrl+p` | 显示 / 隐藏会话文件路径 |
| `ctrl+r` | 重命名选中会话 |
| `ctrl+d` | 删除选中会话(**先确认**;当前会话删不掉) |
| `escape` | 先退出重命名态 / 取消删除确认,再关面板 |

## 树选择器(`/tree`)

| 键 | 行为 |
| --- | --- |
| 输入框打字 | 搜索节点(空格分词,全部命中才显示) |
| `↑` / `↓` / `enter` | 选 / 跳到该节点继续 |
| `ctrl+d` / `ctrl+t` / `ctrl+u` / `ctrl+l` / `ctrl+a` | 过滤:默认(隐藏状态类)/ 隐藏工具结果 / 只看用户消息 / 只看有标签 / 全部 |
| `ctrl+o` / `shift+ctrl+o` | 过滤模式循环 / 反向循环 |
| `shift+l` | 编辑标签(`enter` 保存;留空 = 清除) |
| `shift+t` | 标签是否附带时间戳 |
| `escape` | 先退出标签编辑,再关面板 |
