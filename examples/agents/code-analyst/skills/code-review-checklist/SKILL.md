# 代码评审核对清单

按序逐项检查,输出到评审结论:

1. **结构一致性**:分层、依赖方向、命名是否与现有代码一致?
2. **边界处理**:空值 / 超限 / 并发 / 异常路径是否覆盖?
3. **安全**:注入、越权、敏感信息泄漏?
4. **测试**:新增行为是否有用例?既有用例是否被破坏?
5. **可维护性**:重复代码、魔法数字、缺失注释(只在高复杂度处)。

每个问题按「文件:行号 → 问题 → 建议」输出;最后给总体结论与优先级排序。
